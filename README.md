# Mahbod Mehramiz — Portfolio

Personal portfolio site built with React + Vite + Tailwind CSS.

## Setup

```bash
npm install
npm run dev
```

## Deploy

Push to GitHub and import on [Vercel](https://vercel.com) — it auto-detects the Vite config.

## Customization

- **Photo**: Place your `headshot.jpg` in the `public/` folder
- **Demo video**: Place your `demo-video.mp4` in the `public/` folder
- **Links**: Update GitHub/Live Demo URLs in the Ghost Job Detector section of `src/App.jsx`
